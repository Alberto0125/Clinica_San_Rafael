# Clinica_San_Rafael
# Sistema de Digitalización de Expedientes Médicos

## Descripción
Sistema web para la Clínica San Rafael que permite registrar pacientes,
consultar expedientes médicos y llevar el historial de consultas del
personal médico, reemplazando el manejo de expedientes en papel.

## Objetivo
Facilitar el registro, la búsqueda y la consulta de expedientes médicos
de forma rápida y segura, con acceso controlado según el rol de cada
usuario.
